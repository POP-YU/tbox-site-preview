需要 API key 吗？

需要。T-Box 不内置任何 key；你在设置中填入自己的模型服务 key，模型费用、配额与数据处理规则由提供方决定。

3 小时试用怎么算？

只在软件实际运行时累计，关闭软件后停止。试用用于验证设备、简历二次分析、本地 SenseVoice 转写与读屏识题链路。

简历会不会上传？

导入和本地整理先发生在你的电脑上；当你选择把内容发送给云端模型做分析时，简历片段会按该模型提供方的规则处理。不要把不愿发送的敏感信息放进请求。

音频怎么处理？

本地 SenseVoice 可先在本机完成转写；如果你改用云端转写或把文字交给云模型，音频/文字是否离开本机取决于你的选择和提供方。

读屏识题需要什么？

需要可读的题面区域、正常的屏幕采集权限和你配置的视觉模型。题面模糊、权限被拒或 key 无额度时，识别可能失败；页面不会把它描述成“自动答题”。

三档答案有什么区别？

极速约 60 字用于先抓重点，标准约 90 字用于口述组织，深思给更完整的结构化建议。长度是目标区间，不是正确率或延迟承诺。

支持哪些求职场景？

首页按校招、社招、转行和留学生场景说明落点；能力仍以简历、题面、转写、术语包和三档回答为边界，不承诺替代教练或招聘方。

答案一定正确吗？

不一定。模型可能误读题面、忽略你的经历或生成不合适的措辞。关键事实、数字和承诺请由你自己核对。

价格会自动续费吗？

不会。当前门户展示一次性卡密：体验卡 ¥9.9、月卡 ¥29、季卡 ¥69。模型 API 费用另计，购买前请先用试用验证。

购买后如何激活？

购买页交付卡密后，按卡密教程输入；若页面显示的版本或激活提示与实际软件不一致，先保留原始错误与版本号。

下载页为什么有“待填”？

安装包字节数与 SHA256 均取自本机打包产物实测，并已与 Release 上传后回传的 digest 逐字节核对；不使用旧版哈希冒充新版。

遇到问题怎么排查？

先记录版本、key 提供方、权限提示和原始错误；不要修改安装目录。再按下载页的哈希命令与激活教程逐项复核。
