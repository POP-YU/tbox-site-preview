立即购买

购买后需要注册吗？

不需要注册账号。当前在线购买与自动发货尚未开放；拿到卡密后在启动器中激活，具体步骤见激活教程。

为什么要安装根证书？

测试版用本地根证书签名，让 Windows 能校验安装器与产品内部组件。安装器会在安装时把这张根证书加入本机信任库；卸载时它会弹窗问「是否同时删除根证书」，选「是」。选「否」的话这张自建根会一直留在你的信任库里——它不在微软公信根名单内，留着没用。也正因为是自建根，安装之前系统并不认这个签名，这就是下面那条提示的由来。

卸载后那张根证书还在吗？

取决于你在卸载确认框里点的哪个按钮。选「是」——已经删掉；选「否」——还在。想手动确认或清理：certutil -store Root "T-Box Local Root CA" 能查到就是还在，用以管理员身份运行 certutil -delstore Root "T-Box Local Root CA" 即可删除。

Windows 提示「已保护你的电脑 / 未知发布者」，要不要继续？

先暂停核对来源与文件哈希。确认可信之后，再自行决定是否点更多信息 → 仍要运行。原因是那张本地根证书在安装之前还没进系统信任库，不是文件坏了。判断文件有没有被调包别看这个提示，看 SHA256：下载页给了期望值和 Get-FileHash 命令，只能证明它与该期望值一致；期望值本身也必须来自你信任的发布渠道。自签证书谁都能造一张同名的，哈希对不上就别运行。

浮窗会出现在屏幕共享里吗？

提示盒使用内容保护标志降低录屏暴露；不同会议软件和独占全屏的表现以现场环境为准。

答案为空怎么办？

先核对网络与模型配置，查看启动器状态行；可以尝试“一键恢复”。没有余额页。不要修改安装目录文件，若仍失败请保留日志与原始错误。

如何校验安装包？

在 PowerShell 运行下载页给出的 Get-FileHash 命令，对比页面 SHA256。

去下载试用版
现在买了卡密能激活吗？

最新版本：能。卡密格式为 TB-YYYYMMDD-PLAN-SEQ4-CHK4#签名，使用 Ed25519 签名，启动器用内置公钥在本机离线验签——不联网、不连服务器、不自动续费。验过之后在本机写一份 DPAPI 加密的授权文件（%LOCALAPPDATA%\TBox\license.bin）。旧版：不能。那些版本把卡密发往占位地址 https://旧版占位激活地址（example.com 永不指向真实服务器），点「激活」只会返回「激活失败：…」。用卡密请先装 最新版本。

那现在怎么用？

不激活也能用 7 天——启动器状态行写的就是「试用模式 · 激活后解除限制」。这 7 天足够验证声卡、显示器、题面识别和字幕位置是不是你要的。到期后启动器会显示「试用已结束 · 输入授权卡密后点击激活」。

我自己有授权服务，能接吗？

不用接了。最新版本的激活不再走网络：卡密本身带签名，验签只用内置公钥，启动器不会发起任何在线激活请求（旧的 POST /activate 调用已从源码里删掉）。签发私钥只在发卡侧保管；用户不需要接入自己的授权服务器。

离线授权能远程吊销、换机或续期吗？

离线卡不能远程吊销：启动器只在本机验签，不向服务器查询吊销状态。绑机卡换机需补发新卡，未绑机卡可直接换机；到期续用需补发新卡。

免费试用 7 天和体验卡 7 天是什么关系？

两者都是 7 天，时长档位重复，二选一没有时长档位增量，也不会自动叠加成 14 天。体验卡按签发时的绝对到期时间计算，不会接在免费试用之后自动顺延；具体截止时间以卡密为准。本页不调整价格。
