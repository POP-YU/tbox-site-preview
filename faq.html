常见问题

立即购买

购买后需要注册吗？

不需要。支付成功后卡密自动发到购买页面或邮箱。

为什么要安装根证书？

测试版用本地根证书签名，让 Windows 能校验安装器与产品内部组件。安装器会在安装时把这张根证书加入本机信任库；卸载时它会弹窗问「是否同时删除根证书」，选「是」。选「否」的话这张自建根会一直留在你的信任库里——它不在微软公信根名单内，留着没用。也正因为是自建根，安装之前系统并不认这个签名，这就是下面那条提示的由来。

卸载后那张根证书还在吗？

取决于你在卸载确认框里点的哪个按钮。选「是」——已经删掉；选「否」——还在。想手动确认或清理：certutil -store Root "T-Box Local Root CA" 能查到就是还在，用以管理员身份运行 certutil -delstore Root "T-Box Local Root CA" 即可删除。

Windows 提示「已保护你的电脑 / 未知发布者」，要不要继续？

要。点更多信息，再点仍要运行。原因是那张本地根证书在安装之前还没进系统信任库，不是文件坏了。判断文件有没有被调包别看这个提示，看 SHA256：下载页给了期望值和 Get-FileHash 命令，对得上才是官方包。自签证书谁都能造一张同名的，哈希对不上就别运行。

浮窗会出现在屏幕共享里吗？

提示盒使用内容保护标志降低录屏暴露；不同会议软件和独占全屏的表现以现场环境为准。

答案为空怎么办？

先查看状态页中的余额、网络和模型状态；不要修改安装目录文件。若任务失败，保留日志后联系售后。

如何校验安装包？

在 PowerShell 运行下载页给出的 Get-FileHash 命令，对比页面 SHA256。

购买通道正在开通

卡密走发卡平台自动发货，商户号与回调还在配置中，所以现在还不能直接下单。开通后这块会直接变成购买入口，不用重新找。

在那之前可以先下载 0.1.21 免费试用：用你自己的真实题面验证设备、字幕位置和共享表现，验完再决定买不买。

去下载试用版

现在买了卡密能激活吗？

0.1.22 及更新版本：能。卡密形如 TB1.…….……，自带发行方 RSA 签名，启动器用内置公钥在本机验——不联网、不连服务器、不自动续费。验过之后在本机写一份 DPAPI 加密的授权文件（%LOCALAPPDATA%\TBox\license.bin）。0.1.21 及更早版本：不能。那些版本把卡密发往占位地址 https://license.tbox.example.com（example.com 永不指向真实服务器），点「激活」只会返回「激活失败：…」。用卡密请先装 0.1.22 或更新版本。

那现在怎么用？

不激活也能用 7 天——启动器状态行写的就是「试用模式 · 激活后解除限制」。这 7 天足够验证声卡、显示器、题面识别和字幕位置是不是你要的。到期后启动器会显示「试用已结束 · 输入授权卡密后点击激活」。

我自己有授权服务，能接吗？

不用接了。0.1.22 起激活不再走网络：卡密本身带签名，验签只用内置公钥，启动器不会发起任何在线激活请求（旧的 POST /activate 调用已从源码里删掉）。你唯一要保管的是签发私钥——它只在发卡侧存在，安装包和启动器里都没有。
